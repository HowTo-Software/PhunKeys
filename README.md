# PhunKeys
The goal of this little experiment is to see if I can make cars sellable in a server using PhunMart's shops and a few slightly modded vanilla items. 
Assets used are the Base.CarKey, Phunmarts own vehicle claim key, lament box model, and a few sounds yoinked from the web. 
Put key in box, right click box, select Transmute, sell the key at the shop for the designated price.
