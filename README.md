# PhunKeys
Assets used are the Base.CarKey, lament box model, and a few sounds yoinked from the web. 
PhunKeys uses Base.CarKey and a custom Vehicle Conversion Box to convert a real vehicle into a sellable trade-in key for PhunMart.
The resulting key does not preserve the original vehicle's state or claim data. It exists only as a trade-in item that PhunMart can recognize and purchase.
Put key in box, right click box, select Transmute, sell the key at the shop for the designated price.
